# AFC Steak – Landing Page

Landing page untuk **AFC Steak** (Good steak, good mood). Dibuat dengan HTML, CSS, dan JavaScript biasa, tanpa framework.

## Cara menjalankan
1. Buka folder ini di VS Code.
2. Klik kanan `index.html`, lalu pilih **Open with Live Server**.

Atau cukup buka `index.html` langsung di browser.

## Mengubah isi
- **Nomor WhatsApp**: ubah `CONFIG` di bagian atas `script.js`.
- **Foto**: timpa file `.jpg` di folder ini dengan nama file yang sama.
- **Link Instagram/TikTok**: ubah di bagian footer `index.html`.

## Deploy gratis dengan GitHub Pages
1. Upload semua file ke repository GitHub (`index.html` harus di folder paling luar).
2. Buka **Settings > Pages**.
3. Pada **Source**, pilih branch `main` dan folder `/ (root)`, lalu **Save**.
4. Website aktif beberapa menit kemudian di `https://username.github.io/nama-repo/`.

## Struktur file
```
index.html   halaman utama
style.css    tampilan
script.js    pengaturan dan animasi
*.jpg        foto menu, tim, dan testimoni
```
